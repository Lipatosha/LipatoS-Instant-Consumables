# LipatoS — Мгновенное употребление

**v1.3.0** · Foundry VTT v14 · D&D 5e 6.0.6

Использование предметов инвентаря без диалогов подтверждения, с обычной карточкой предмета D&D5e в чате.

## Какие предметы расходуются

Автоматически расходуются следующие физические типы предметов D&D5e:
- **Расходуемые предметы** (`consumable`).
- **Добыча / прочие предметы** (`loot`).
- **Инструменты** (`tool`).
- **Оружие** (`weapon`) — только при отдельном выборе **«Использовать»** в ПКМ или применении утилитарной активности. **Обычные атаки оружием не расходуют его автоматически.**

**Исключены без исключений:** `equipment` (снаряжение), `container` (контейнеры), устаревший `backpack`. Также не затрагиваются заклинания, особенности, классы и прочие неинвентарные документы.

**Важно:** бочку пива, созданную с типом «Снаряжение», модуль больше не будет расходовать. Чтобы пить из неё с автоматическим списанием, создай её как **«Расходуемый предмет»** с зарядами.

## Что происходит при использовании

1. В чат отправляется обычная карточка предмета с изображением, названием и описанием.
2. Если у предмета настроены заряды (`system.uses.max > 0`), списывается **1 заряд** через `system.uses.spent`. Когда заряды закончатся, пустой предмет остаётся в инвентаре.
3. Если зарядов нет, списывается **1 единица количества** через `system.quantity`; последняя единица удаляется.
4. Если отправка карточки отменена, состояние предмета не меняется. Повторное быстрое нажатие не списывает дважды.

Настраиваемый модуль **LipatoS-item-move-stack v34.2.3+** использует публичный интерфейс этого дополнения, поэтому ПКМ → «Использовать» работает и у вещей без стандартных активностей, например добычи и инструментов. Динамические масса и стоимость зарядов продолжают пересчитываться после изменения `system.uses.spent`.

Для отдельных предметов можно отменить обработку флагом `flags.lipatos-instant-consumables.enabled = false`. Исключённые типы нельзя включить этим флагом.

## Установка

```text
https://raw.githubusercontent.com/Lipatosha/LipatoS-Instant-Consumables/main/module.json
```

В менеджере модулей установите или обновите дополнение, включите его в мире и обновите страницу у игроков.

## История версий

- **1.3.0** — любые физические предметы инвентаря, кроме снаряжения и контейнеров; интеграция с ПКМ, защита обычных атак оружием.
- **1.2.0** — зарядовые сосуды и напитки.
- **1.1.0** — карточка в чате.
