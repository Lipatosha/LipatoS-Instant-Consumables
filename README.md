# LipatoS — Мгновенное употребление

Модуль для **Foundry VTT v14** и **D&D 5e 6.0.6**: еда и напитки используются **без диалогов подтверждения**, но с обычной карточкой предмета в чате.

## Установка

В менеджере модулей Foundry вставьте манифест:

```text
https://raw.githubusercontent.com/Lipatosha/LipatoS-Instant-Consumables/main/module.json
```

После установки включите модуль в мире и обновите страницу у всех участников.

## Использование (v1.2.0)

Используйте активность предмета или **ПКМ → «Использовать»** из модуля LipatoS-item-move-stack.

- **Пивная бочка, кувшин или другой напиток с зарядами:** моментально списывается **1 заряд** через `system.uses.spent`. Бочка с последним израсходованным зарядом **остаётся** в инвентаре как пустая тара; при отсутствии зарядов расход блокируется.
- **Еда без зарядов:** уменьшается количество `system.quantity` на 1; последняя штука удаляется.
- **В чат** один раз отправляется обычная карточка D&D 5e с названием и описанием предмета. Если её создание отменено или завершилось ошибкой, предмет не расходуется.
- **Никаких запросов** «Потратить заряд?» — стандартная активация перехватывается до диалога D&D 5e.

Модуль обрабатывает предметы с подтипом **food**, известные блюда и напитки Аиндора, а также предметы с говорящими названиями (например, «Бочка пива „Последняя медь“»), даже если их тип — **«Экипировка»**. Зелья, свитки, оружие и магические жезлы остаются без изменений.

Для иных предметов ГМ может явно включить функциональность флагом `flags.lipatos-instant-consumables.enabled = true` или отключить его значением `false`.

**Совместимость с LipatoS-item-move-stack 34.2.2+**: когда у бочки настроен динамический вес и стоимость заряда, изменение `system.uses.spent` автоматически пересчитывает массу и цену штатными обработчиками второго модуля. Переустанавливать или перенастраивать бочку не нужно.
