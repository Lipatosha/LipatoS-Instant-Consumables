# LipatoS — Мгновенное употребление

Модуль для **Foundry VTT v14** и **D&D 5e 6.0.6**, позволяющий использовать еду и напитки без дополнительных диалогов.

## Установка

В Foundry: **Настройки → Управление модулями → Установить модуль → Установить по ссылке**.

Манифест:

```text
https://raw.githubusercontent.com/Lipatosha/LipatoS-Instant-Consumables/main/module.json
```

После установки активируйте модуль в своём мире.

## Использование

Нажмите **«Использовать»** у активности пищевого расходуемого предмета (или используйте активность с листа персонажа):

- Если предметов 4, станет 3.
- Если предметов 1, предмет будет удалён из инвентаря.
- Без дополнительных подтверждений: при употреблении публикуется **стандартная карточка предмета D&D 5e в чате**, затем списывается одна порция.

Модуль автоматически работает со всеми предметами типа «Расходуемый предмет» с подтипом **food**, а также со всеми напитками и блюдами Аиндора, перечисленными в коде (даже если их подтип другой).

**Важно:** обычное открытие карточки предмета для редактирования *не* расходует его; расход происходит при использовании активности. Зелья, свитки и прочие расходники не изменяются автоматически.

Владелец персонажа должен иметь право менять его инвентарь.

Для пользовательского расходуемого предмета можно включить мгновенное употребление флагом `flags.lipatos-instant-consumables.enabled = true`.
